## Welcome! 👋

Thanks for checking out this front-end coding challenge.

## :scroll: Description 

A responsive landing page for the fictional digital bank, Easybank, built with modern frontend technologies. This project is based on the Frontend Mentor design challenge and implemented with a mobile-first approach.

- ⚛ React — Component-based architecture

- ⚡ Vite — Lightning-fast dev server and bundler

- 🎨 Tailwind CSS v4.1 — Utility-first styling with custom theming

- 🛠 TypeScript — Type-safe development

- 🖼 SVG & Responsive Images — Optimized asset handling

## 📱 Features

✅ Fully responsive across mobile, tablet, and desktop

✅ Accessible components with ARIA labels and keyboard navigation

✅ Reusable React components (ArticleCard, Button, Navbar, Footer, etc.)

✅ Custom Tailwind config with extended colors, fonts, and letter spacing

✅ Mobile hamburger menu with smooth transitions
  

## :rocket: Installation & Usage 

```
# Clone the repo
git clone https://github.com/olivcamj/easybank-landing.git

# Navigate into the project directory
cd easybank-landing

# Install dependencies
npm install

# Start the development server
npm run dev

```

## 🗂 Folder Structure

```
src/
├── assets/            # Images, SVGs and fonts
├── components/        # Reusable UI components
├── App.tsx            # Root component
├── main.tsx           # Entry point
└── index.css          # Tailwind & font imports
```
